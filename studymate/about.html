About & Help

Learn how to use the website and keep your study plans organised.

What is StudyMate?

StudyMate is a student web development project that helps people record assignments and plan study sessions. The website is made using HTML, CSS and JavaScript. It is designed for beginners who need a straightforward way to organise their week.

You can use the website without creating an account. Everything is managed directly on the pages using your browser.

How to use My Tasks

  1. Open My Tasks using the navigation menu.
  2. Enter the assignment name, optional subject and due date.
  3. Choose a priority and select Add task.
  4. Mark work as completed with its checkbox, or remove a task with Delete.
  5. Use the filters to see all, unfinished or completed tasks.

How to use the Study Planner

  1. Open Study Planner.
  2. Enter an activity and choose a day, time and duration.
  3. Select Add to my week.
  4. Review sessions for each day and remove sessions you no longer need.

Privacy and limitations

StudyMate saves information using browser local storage. Your entries stay on the current browser and device. Clearing browser storage, using private mode or switching devices may remove or hide your saved entries.

This website has no login system, database, reminders or automatic cloud backup. Do not enter passwords, health information or other sensitive personal details in tasks.
