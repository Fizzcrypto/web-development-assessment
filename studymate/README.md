# StudyMate — Student Assignment and Study Planner

Live website: https://fizzcrypto.github.io/web-development-assessment/studymate/

StudyMate is a four-page student planning website developed as a web development group project.

## Pages
- `index.html` — Home, introduction and navigation
- `tasks.html` — Add, complete, filter and remove assignments
- `planner.html` — Create and remove recurring weekly study sessions
- `about.html` — About & Help, data storage and limitations

## Other project files
- `styles.css` — shared responsive styles
- `app.js` — task and planner functionality using browser localStorage

## Running locally
Download this folder, then open `index.html` in a browser, or serve it using VS Code Live Server.

No external images or JavaScript dependencies are used. Saved data stays in the visitor's browser; there is no login or online database.

## Hosting
The website is published using GitHub Pages. It lives within the `studymate` folder so it does not replace other repository assignments.
